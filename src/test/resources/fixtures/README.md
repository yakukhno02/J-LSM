# J-LSM Binary Test Fixtures (M0)

Ця директорія містить еталонні бінарні файли мінімального WAL (`wal-minimal.bin`) та SSTable (`sstable-minimal.bin`), створені згідно зі специфікацією в `docs/DEVELOPMENT.md` (розділ 4) з вручну перевіреними контрольними сумами IEEE 802.3 CRC32.

---

## 1. `wal-minimal.bin` (Розмір: 88 байтів)

Файл представляє мінімальний Write-Ahead Log із загальним 32-байтовим заголовком і двома записами:
1. `PUT` (sequence = 1, key = `"key1"`, value = `"value1"`)
2. `DELETE` (sequence = 2, key = `"key2"`, value = `null`)

### Побайтне розбиття структури:

| Зміщення (байти) | Розмір (B) | Поле | Значення (Big-Endian) | Опис |
| :--- | :--- | :--- | :--- | :--- |
| **00..03** | 4 | Magic | `0x4A57414C` | ASCII "JWAL" |
| **04..07** | 4 | Format Version | `0x00000001` | Версія формату = 1 |
| **08..15** | 8 | File ID | `0x0000000000000001` | ID файлу = 1 |
| **16..19** | 4 | Block Size | `0x00000000` | Для WAL = 0 |
| **20..23** | 4 | Reserved | `0x00000000` | Зарезервовано = 0 |
| **24..27** | 4 | Header Size | `0x00000020` | Розмір заголовка = 32 |
| **28..31** | 4 | Header CRC32 | `0xFBB79D6F` | CRC32 над байтами 0..27 |
| **32..35** | 4 | Frame 1 CRC32 | `0x5B799445` | CRC32 над корисним навантаженням Frame 1 (байти 36..62) |
| **36..43** | 8 | Frame 1 Sequence | `0x0000000000000001` | Sequence = 1L |
| **44** | 1 | Frame 1 Type | `0x01` | 0x01 = PUT |
| **45..48** | 4 | Frame 1 KeyLen | `0x00000004` | Довжина ключа = 4 |
| **49..52** | 4 | Frame 1 ValLen | `0x00000006` | Довжина значення = 6 |
| **53..56** | 4 | Frame 1 Key | `6b 65 79 31` | ASCII "key1" |
| **57..62** | 6 | Frame 1 Val | `76 61 6c 75 65 31` | ASCII "value1" |
| **63..66** | 4 | Frame 2 CRC32 | `0x09CB0F97` | CRC32 над корисним навантаженням Frame 2 (байти 67..87) |
| **67..74** | 8 | Frame 2 Sequence | `0x0000000000000002` | Sequence = 2L |
| **75** | 1 | Frame 2 Type | `0x02` | 0x02 = DELETE |
| **76..79** | 4 | Frame 2 KeyLen | `0x00000004` | Довжина ключа = 4 |
| **80..83** | 4 | Frame 2 ValLen | `0x00000000` | Довжина значення = 0 (DELETE) |
| **84..87** | 4 | Frame 2 Key | `6b 65 79 32` | ASCII "key2" |

### Контрольні суми (CRC32):
- **Header CRC32 (зміщення 0..27):** `0xFBB79D6F`
- **Frame 1 Payload CRC32 (зміщення 36..62, 27 байтів):** `0x5B799445`
- **Frame 2 Payload CRC32 (зміщення 67..87, 21 байт):** `0x09CB0F97`

## 2. `sstable-minimal.bin` (Розмір: 4196 байтів)

Файл представляє мінімальний валідний SSTable з 1 блоком даних (4096 байтів), блоком рідкісного індексу (Sparse Index) та підніжжям (Footer):

1. **Common Header (32 байти, зміщення 0..31):**
   - Magic: `0x4A535354` (ASCII "JSST")
   - Version: 1
   - File ID: 1L
   - Block Size: 4096 (`0x00001000`)
   - Reserved: 0
   - Header Size: 32 (`0x00000020`)
   - **Header CRC32 (над 0..27):** `0x765CD30C`

2. **Data Block 0 (4096 байтів, зміщення 32..4127):**
   - `recordCount`: 2 (`0x00000002`)
   - `usedBytes`: 56 (`0x00000038`) — вказує на кінець даних записів
   - **Record 1 (PUT):**
     - Sequence: 1L
     - KeyLen: 4, ValLen: 6
     - Flags: `0x00` (PUT)
     - Key: `"key1"`, Value: `"value1"`
     - Розмір: 27 байтів (зміщення 40..66)
   - **Record 2 (DELETE):**
     - Sequence: 2L
     - KeyLen: 4, ValLen: 0
     - Flags: `0x01` (DELETE)
     - Key: `"key2"`, Value: `[порожньо]`
     - Розмір: 21 байт (зміщення 67..87)
   - **Zero Padding:** зміщення 88..4123 заповнені `0x00` (4036 байтів)
   - **Data Block CRC32 (над байтами 32..4123, тобто перші 4092 байти блоку):** `0x539D931A` (записано у зміщення 4124..4127)

3. **Sparse Index Block (28 байтів, зміщення 4128..4155):**
   - `blockCount`: 1 (`0x00000001`)
   - `blockOffset`: 32L (`0x0000000000000020`)
   - `blockSize`: 4096 (`0x00001000`)
   - `firstKeyLen`: 4 (`0x00000004`)
   - `firstKeyBytes`: `"key1"` (`6b 65 79 31`)
   - **Index CRC32 (над першими 24 байтами індексу):** `0x50539E2F` (записано у зміщення 4152..4155)

4. **Footer (40 байтів, зміщення 4156..4195):**
   - `indexOffset`: 4128L (`0x0000000000001020`)
   - `indexLength`: 28L (`0x000000000000001C`)
   - `totalRecordCount`: 2L (`0x0000000000000002`)
   - `blockCount`: 1 (`0x00000001`)
   - `formatVersion`: 1 (`0x00000001`)
   - `magic`: `0x4A4C534D` (ASCII "JLSM")
   - **Footer CRC32 (над першими 36 байтами підніжжя):** `0xEEC0FA42` (записано у зміщення 4192..4195)
